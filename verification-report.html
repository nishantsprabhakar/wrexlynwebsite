05 / Evidence boundary

What this report does not claim

Not a SWE-bench score

No SWE-bench, Terminal-Bench, BFCL or SWE-Lancer result is claimed. Those require benchmark-specific adapters, pinned models, isolated task environments and external scoring.

Not an uptime SLA

Response times are single observations from one client and network path, not percentile latency, availability history or a service-level guarantee.

Not a penetration test

Header inspection and automated regression tests do not replace an independent security assessment.

Not user validation

Architecture and tests do not demonstrate adoption, retention, customer outcomes or willingness to pay.
