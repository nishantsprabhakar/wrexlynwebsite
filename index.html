THE QUESTIONS THAT MATTER

BEFORE YOU TRUST
AN AGENT.

Does Wrexlyn require a specific model?

No. It supports configured hosted providers and compatible local or custom endpoints. The execution and verification workflow remains Wrexlyn’s.

Does source code or business data have to leave the machine?

No mandatory Wrexlyn cloud is required. Data movement depends on the model provider and integrations selected by the customer; local models can keep model inference local.

How does Wrexlyn know that work succeeded?

It collects deterministic project checks, artifact quality gates and critic evidence, then derives an explicit verification outcome instead of treating model confidence as proof.

Is the browser demo the full product?

No. It is intentionally limited. The full product operates against a real customer-controlled workspace with tools, approvals, verification, artifacts and recovery.

Is Wrexlyn open source?

No. Wrexlyn is proprietary software created by Nishant Prabhakar. Product documentation and selected evaluation evidence are public; the application source is not offered for download.
